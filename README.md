# 生成艺术 SVG 海报设计器

参数化生成艺术工具，支持螺旋、分形树、波浪、圆环、噪声场五种图案，8 种颜色主题，SVG/PNG 导出。

## 功能

- 5 种图案类型：螺旋、分形树、波浪、圆环、噪声场
- 8 种预设颜色主题（日落、海洋、霓虹、森林、单色、糖果、火焰、极光）
- 种子随机数生成器（确定性重现）
- 参数实时预览：迭代数、缩放、旋转、描边、透明度
- **作品链接复现**：一键把当前全部参数（含 FNV-1a 校验码）编码进地址栏，他人打开同一链接即还原同一张作品
- **最近打开记录**：localStorage 持久化最近打开的作品，一键回到任意一份，支持单条删除与清空，空态有引导说明
- **链接过期提示**：手动改参数后，原分享链接标记为「已过期」，可放弃修改或重新复制；参数缺失、越界、篡改时退回默认作品并说明原因
- SVG 矢量导出 & PNG 高清导出

## 分享链接格式

参数以短键写入 query string（如 `?p=wave&s=12345&...&c=8f1c2a3d`），`c` 为对其余字段的 FNV-1a 校验码：

- 校验码缺失/不匹配 → 判定为损坏或篡改，整体退回默认作品
- 校验通过但单字段缺失或越界 → 该字段回落默认值，并在页面顶部说明原因
- 同一作品的编码唯一确定，刷新后地址栏与复制出去的链接始终一致
